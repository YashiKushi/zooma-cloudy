# HappVPN — iOS VPN & Proxy клиент (по типу Happ)

Проект VPN-клиента под iPhone (iOS) с поддержкой протоколов **VLESS (Reality), VMess, Trojan, Shadowsocks**, созданный в стиле популярного приложения **Happ (Proxy Utility)**.

---

## 📱 Вариант 1: Установка оригинального Happ прямо сейчас (Рекомендуется)

Если вам нужно готовое приложение без самостоятельной компиляции:

1. **Официальный App Store:**
   - В большинстве стран приложение доступно официально: введите в поиске App Store **"Happ - Proxy Utility"** (разработчик *Flyfrog LLC*).
   - Приложение полностью бесплатное и сразу готово к работе.
2. **Если Happ недоступен в вашем регионе App Store:**
   - Смените регион Apple ID на США/Польшу/Казахстан (карту привязывать не требуется для бесплатных приложений) и скачайте напрямую из App Store.
3. **Готовые проверенные открытые аналоги:**
   - **Sing-box for iOS** — мощнейший открытый клиент для всех протоколов.
   - **FoXray** — клиент на базе Xray ядра для iOS.
   - **Streisand** — популярный клиент для iOS.
   - **V2Box** — клиент для VLESS / Trojan / Shadowsocks.

## 🛠 Вариант 2: Сборка своего IPA через GitHub Actions (Без наличия Mac)

Поскольку сборка iOS-приложений (`.ipa`) требует окружения macOS и Xcode, для пользователей на Windows подготовлен автоматический пайплайн **GitHub Actions**:

1. Создайте бесплатный репозиторий на [GitHub.com](https://github.com).
2. Загрузите файлы этого проекта в свой репозиторий.
3. Перейдите во вкладку **Actions** в репозитории.
4. Запустите workflow **Build HappVPN IPA** (или просто сделайте `git push`).
5. Облачный сервер Apple (macOS) скомпилирует проект и сформирует готовый файл **`HappVPN.ipa`** в блоке **Artifacts**.
6. Скачайте `.ipa` файл на компьютер или телефон.

## 📲 Как установить скачанный `.ipa` файл на iPhone

Установить `.ipa` на iPhone можно следующими способами:

1. **TrollStore** (iOS 14.0 — 16.6.1 / 17.0):
   - Откройте скачанный `.ipa` файл на iPhone и выберите «Открыть в TrollStore». Устанавливается навсегда без переподписи и без лимитов на сертификаты.
2. **Sideloadly** (Windows / macOS):
   - Скачайте Sideloadly на ПК, подключите iPhone кабелем.
   - Перетащите файл `.ipa` в окно Sideloadly, укажите ваш бесплатный Apple ID и нажмите «Start».
3. **AltStore / SideStore**:
   - Установка через локальный сервер подписи (обновление каждые 7 дней).
4. **Скарлет (Scarlet) / Корпоративный сертификат**:
   - Установка напрямую через мобильный браузер Safari при наличии действующего сертификата.

## ⚙️ Архитектура клиента

- **HappVPNApp.swift**: Точка входа SwiftUI приложения.
- **ContentView.swift**: Главный экран со статусом соединения, кнопкой подключения, замером пинга и импортом ссылок.
- **ProxyConfig.swift**: Парсер ссылок `vless://`, `vmess://`, `trojan://`, `ss://`.
- **VPNManager.swift**: Менеджер управления профилем `NETunnelProviderManager`.
- **PacketTunnelProvider.swift**: Системное расширение iOS `NetworkExtension` для перенаправления сетевого трафика.
